# Аудит неиспользуемых функций

Функции ниже не вызываются из `main.ts`, но могут пригодиться для следующих
возможностей, поэтому они оставлены в проекте и помечены JSDoc-комментарием
`@deprecated`.

| Название функции | Где находится | Полезная ли она? (Да/Нет) | Как её можно использовать в будущем? (Идея для фичи) |
| :--- | :--- | :--- | :--- |
| formatBook | task1-types.ts | Да | Показывать краткое описание книги в карточке. |
| calculateAverageYear | task1-types.ts | Да | Показать средний год книг в разделе статистики. |
| filterByMinRating | task3-filters.ts | Да | Добавить фильтр книг по минимальному рейтингу. |
| filterAndSortBooks | task5-utils.ts | Да | Сделать отдельный быстрый поиск по названию. |

Функции `addBook`, `removeBook` и `getBook` из `task2-functions.ts` удалены:
они дублировали ответственность `BookCatalog` и противоречили завершённому
переходу каталога на ООП.
